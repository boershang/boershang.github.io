自制3-RRR简易机器人

从零开始摸索 3-RRR 平面并联机构：我的运动学学习与实践记录

2026年10月7日 · 机器人 / 机构学 / Python / SolidWorks

最近开始接触并联机器人，想找一个具体的机构，把之前学过的机械设计、Python 编程和数学建模知识结合起来。

最后，我选择了 3-RRR 平面并联机构作为自己的入门项目。

这篇文章主要记录我目前做过的事情，包括逆运动学求解、Python 可视化、SolidWorks 三维建模，以及过程中遇到的一些问题。

目前还处于学习阶段，很多理论并没有完全掌握，所以这更像是一篇阶段性的学习笔记，而不是一份完整的研究成果。

01｜为什么选择 3-RRR？

我一直对机器人机构设计和运动分析比较感兴趣。

之前在做智能分拣装置的机械设计时，接触过龙门架、导轨、丝杠传动、同步带以及各种机械装配关系。这些经历让我逐渐意识到，画出一个三维模型只是第一步，更重要的是理解机构为什么能够运动，以及各个零件之间存在怎样的约束关系。

后来在了解并联机器人，以及尤老师关于可重构并联机构的相关研究时，我对这类机构产生了兴趣。

相比一些结构复杂的空间并联机器人，3-RRR 平面并联机构相对容易理解。

它由三条支链共同连接一个动平台，每条支链包含三个转动副（R 表示 Revolute Joint）。虽然结构看起来不算复杂，但其中涉及逆运动学、正运动学、工作空间和奇异性分析等一系列问题。

对我来说，它正好是一个合适的起点。

我希望先通过一个简单的平面机构，逐步建立从数学建模、程序计算到三维机构设计的完整认识。

02｜开始之前，我有哪些基础？

在机械设计方面，我主要使用 SolidWorks，目前也在进行智能分拣装置的机构设计。

从零件建模到装配关系设置，我已经有了一些实践经验，但对于复杂机构的运动约束和动力学问题，还需要进一步学习。

编程方面，我比较熟悉 Python，之前做过数学建模中的几何计算、参数扫描、结果可视化和灵敏度分析。

在2026年全国大学生数学建模竞赛中，我担任编程手，最终获得省一等奖。

这些经历让我对用程序解决数学问题比较熟悉，也让我产生了一个想法：

能不能通过 Python，把机器人机构的运动过程真正计算出来，再用三维模型验证？

当然，目前我的理论基础还不够完整。

特别是雅可比矩阵、奇异性分类、刚度建模以及并联机构的正运动学，这些都是接下来需要重点补充的内容。

03｜第一个小目标：实现 3-RRR 逆运动学求解

我首先尝试用 Python 编写一个 3-RRR 平面并联机构的逆运动学求解程序。

为了降低初期建模的复杂度，我采用了比较标准的几何模型：

  • 固定平台和动平台均为等边三角形。
  • 三条支链分别由两段连杆连接。
  • 每条支链包含三个转动副。
  • 输入动平台目标位姿，计算三个主动关节角度。

程序的主要输入包括固定平台边长、动平台边长、两段连杆长度 L1 和 L2，以及动平台的目标位姿 (x, y, φ)。

输出则是三个主动关节角 θ1、θ2、θ3，以及各条支链可能出现的几何构型。

我是怎么理解逆运动学的？

最开始接触逆运动学时，我觉得它可能需要比较复杂的数学推导。

但在这个简化模型中，可以先把问题拆开来看。

第一步，根据动平台中心的位置和旋转角度，计算三个连接点 C1、C2、C3 的坐标。

第二步，分别分析三条支链。

对于其中一条支链，固定端 Ai 和动平台连接点 Ci 的位置已知，两段连杆的长度也已知。

这样一来，问题就转化成了一个平面二连杆的几何求解问题。

利用距离公式、反正切函数以及余弦定理，就可以计算主动杆的方向角。

三条支链分别求解，最后便得到整个机构的逆运动学结果。

这让我发现，复杂机构的运动学问题，有时也可以通过合理拆分，转化成几个相对容易处理的几何问题。

04｜第一次运行：为什么会出现八组解？

完成基本求解后，我使用了一组参数进行测试：

参数 数值
固定平台边长 60 mm
动平台边长 60 mm
第一连杆长度 L1 100 mm
第二连杆长度 L2 100 mm
动平台中心 X 35 mm
动平台中心 Y 65 mm
动平台转角 φ 10°

图1：Python 逆运动学程序参数输入。

运行程序后，得到了八组不同的逆运动学分支组合。

一开始看到八组结果时，我还专门思考了一下为什么会出现这种情况。

原因是对于一条平面二连杆支链，在满足几何条件的情况下，通常存在两种不同的弯曲构型。

而 3-RRR 机构共有三条支链，因此理论上最多可以组合出：

2 × 2 × 2 = 8 种逆运动学分支组合。

例如，在这次测试中，其中一组计算结果为：

  • θ1 = -1.178°
  • θ2 = -15.875°
  • θ3 = -2.348°

程序还输出了其余七组分支对应的关节角。

图2：理论上的八种逆运动学分支组合及关节角。

随后，我对计算结果进行了连杆长度一致性检查。

在当前几何假设和测试参数下，程序能够正常完成计算，相关几何约束也得到了满足。

不过，这并不意味着八组结果都能直接用于实际机构。

目前的程序还没有完整考虑关节角限位、连杆之间的干涉以及机构奇异性等问题。

另外，这个 Demo 的代码整理过程中也借助了 AI 辅助，但运动学原理和结果验证仍然是我需要自己继续理解的部分。

05｜把计算结果画出来，再尝试建立三维模型

仅仅输出一组关节角，其实很难直观理解机构到底处于什么状态。

所以，我又尝试用 Python 将其中一个逆运动学分支可视化。

这里选择的是三条支链均采用负号分支的 --- 组合。

图3：3-RRR 平面并联机构的构型可视化。

在图中，可以看到固定平台、动平台、三条支链以及各个连接点之间的几何关系。

相比单纯观察角度数值，这种方式更加直观，也方便后续检查机构的几何构型。

需要说明的是，这张图展示的是一个具体位姿下的机构构型，还不是完整的工作空间分析结果。

从二维计算到 SolidWorks

完成初步的运动学计算后，我开始尝试在 SolidWorks 中建立对应的三维机构模型。

目前主要完成了固定支架、动平台、支链连杆以及部分标准件的建模，并进行了初步装配。

图4：SolidWorks 三维装配模型。

在这个过程中，我发现数学模型和三维装配模型虽然描述的是同一个机构，但关注点并不完全相同。

数学模型更强调几何关系和运动约束，而在 SolidWorks 中，还需要考虑实际零件的连接方式、装配关系以及运动副的设置。

目前，我还没有完成数学模型与三维装配模型之间的对应验证。

下一步准备完善运动副设置和自由度分析，再尝试进行运动仿真，比较 Python 计算结果与 SolidWorks 仿真结果是否一致。

06｜做到这里，我又产生了三个问题

虽然目前已经完成了一个基础的逆运动学 Demo，但我觉得真正值得研究的问题才刚刚开始。

问题一：这个机构的工作空间究竟有多大？

逆运动学程序能够判断某个目标位姿是否存在几何解，但我更想知道：

动平台究竟能够到达哪些位置？

而且，当动平台的旋转角 φ 改变时，即使连杆长度不变，可达位置范围是否也会发生变化？

我准备先固定 φ，利用 Python 进行二维网格扫描，绘制不同姿态下的可达工作空间，再比较结果。

问题二：哪些位置会让机构接近奇异？

这是我目前比较想深入理解的内容。

一个机构存在逆运动学解，并不代表它在该位置就一定具有良好的运动性能。

某些特殊构型可能导致机构接近奇异状态。

虽然已经接触过雅可比矩阵和奇异性这些概念，但我还没有真正建立它们与具体杆件姿态之间的联系。

接下来希望通过具体的几何构型，逐步理解雅可比矩阵的作用，并尝试判断机构的奇异位形。

问题三：怎样判断一组结构参数更合理？

如果改变 L1、L2 或者平台尺寸，机构的工作空间可能会随之变化。

但工作空间更大，就一定代表机构性能更好吗？

有没有可能工作空间扩大了，却同时增加了接近奇异位形的区域？

我希望后续能够通过参数扫描和数值分析，尝试建立一个兼顾可达性与运动性能的评价方法。

07｜接下来准备做什么？

目前给自己安排了三个阶段的小目标。

第一阶段：完善已有的逆运动学程序。

整理 Python 代码，补充不同目标位姿下的测试，并对照 SolidWorks 模型，检查几何定义是否一致。

第二阶段：开展工作空间分析。

先从固定姿态下的二维网格扫描开始，研究不同杆长和平台尺寸对可达区域的影响。

第三阶段：学习雅可比矩阵和奇异性分析。

在理解基础理论后，尝试阅读并复现一篇与 3-RRR 或可重构并联机构相关的论文。

更长远一些，我也希望接触 Stewart 型等空间并联机构，逐步了解更加复杂的机器人机构设计问题。

如果未来有机会参与相关科研项目，我也愿意先从文献整理、数值仿真、程序复现、SolidWorks 建模或者实验辅助等基础工作做起。

写在最后

回头看这段时间的学习，其实目前完成的内容还比较基础。

一个简化的 3-RRR 逆运动学求解程序，一张机构构型可视化图，以及一个还在完善中的 SolidWorks 装配模型。

但对我来说，这已经是一次比较有意义的尝试。

之前接触的数学建模、Python 和机械设计，大多是在不同的任务中分别使用。这次终于尝试把它们放到同一个机器人机构问题里。

过程中也发现，程序能够算出结果，与真正理解机构为什么这样运动，仍然是两回事。

接下来希望不只是让程序运行起来，而是能够逐渐理解计算结果背后的运动学原理，并将它们与实际机构联系起来。

这篇文章就作为我的第一篇 3-RRR 学习记录。后续如果在工作空间、奇异性分析或者运动仿真方面有新的进展，再继续更新。
